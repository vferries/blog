# Archive `/blog/` en grille illustrée — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/blog/` passe d'une liste textuelle à une grille 3 colonnes où chaque billet porte une vignette — son bandeau existant s'il est exploitable, une carte générée sinon.

**Architecture:** Minimal Mistakes rend déjà `.archive__item-teaser` en mode `entries_layout: grid` à partir de `post.header.teaser` ; on câble ce champ sur les 46 billets via le générateur existant, et on remplace la grille en floats du thème par une vraie CSS grid dans `enveille.css`. Le template OG card gagne un mode `variant=teaser` qui masque le titre (déjà réaffiché en `<h2>` sous l'image par MM) et met les tags à sa place.

**Tech Stack:** Jekyll + Minimal Mistakes 4.28.0 (`remote_theme` pinné), CSS custom properties, Chrome headless + ImageMagick pour les cartes, playwright-core (Chrome système) pour les captures. Pas de framework de test dans ce repo : la vérification passe par le build, le grep du HTML généré et les captures.

## Global Constraints

- Spec approuvée : `docs/superpowers/specs/2026-08-04-blog-grid-design.md`
- Seuil de bascule bandeau → carte : **ratio largeur/hauteur > 5:1**, en constante nommée, jamais une liste de slugs en dur
- Tags de la carte teaser : les **3 premiers** du front matter, joints par ` · `
- `paginate: 10` **ne change pas** (passer à 12 supprimerait `/blog/page5/`)
- Le générateur reste **idempotent** et **fidèle aux fins de ligne** (un billet CRLF le reste — cf. bug corrigé en `1aa7ea1`)
- CSS custom properties uniquement, pas de préprocesseur, pas de nouvelle dépendance
- `enveille.css` (chargé partout) et non `landing.css` (chargé sous le flag `is_landing` seulement)
- Les URLs des billets et de la pagination sont intouchées
- Commits : convention FR (`feat:`, `fix:`, `docs:`), pas de co-auteur, direct sur `main` (repo solo)
- Journaliser les branches d'échec (blocs `except`, images illisibles) — jamais d'exception silencieuse

```python
def pose_dans_header(lignes, cle, valeur):
    """Ajoute (ou corrige) header.<cle>. Renvoie (lignes, modifié)."""
    entree = f"  {cle}: {valeur}"

    try:
        i = next(n for n, l in enumerate(lignes) if l.rstrip() == "header:")
    except StopIteration:
        return lignes + ["header:", entree], True

    # Parcourt le bloc indenté qui suit `header:`
    fin = i + 1
    while fin < len(lignes) and (lignes[fin].startswith((" ", "\t")) or not lignes[fin].strip()):
        fin += 1

    for n in range(i + 1, fin):
        if lignes[n].strip().startswith(f"{cle}:"):
            if lignes[n] == entree:
                return lignes, False
            lignes[n] = entree
            return lignes, True

    return lignes[:i + 1] + [entree] + lignes[i + 1:], True
```

- [ ] **Step 2: Ajouter les trois fonctions de lecture**

Insérer juste après `pose_dans_header` :

```python
def header_image(lignes):
    """Valeur de header.image, ou None. Ne confond pas avec og_image."""
    try:
        i = next(n for n, l in enumerate(lignes) if l.rstrip() == "header:")
    except StopIteration:
        return None

    n = i + 1
    while n < len(lignes) and (lignes[n].startswith((" ", "\t")) or not lignes[n].strip()):
        if lignes[n].strip().startswith("image:"):
            return lignes[n].split(":", 1)[1].strip()
        n += 1
    return None


def ratio(chemin):
    """Largeur / hauteur de l'image, ou None si elle est illisible."""
    try:
        mesure = subprocess.run(
            ["magick", "identify", "-format", "%[fx:w/h]", str(chemin)],
            check=True, capture_output=True, text=True,
        ).stdout.strip()
        return float(mesure)
    except (subprocess.CalledProcessError, FileNotFoundError, ValueError) as erreur:
        print(f"    ratio illisible pour {chemin} ({erreur}) — bascule sur une carte")
        return None


def tags(lignes, maximum=3):
    """Les premiers tags du front matter, joints par ' · '.

    Plafonné parce qu'un billet en porte jusqu'à 6 et que les assemblages
    complets atteignent 50 caractères, ce qui déborde la zone laissée libre
    par le titre masqué.
    """
    brut = champ(lignes, "tags")
    if not brut:
        return ""
    brut = brut.strip()
    if brut.startswith("[") and brut.endswith("]"):
        brut = brut[1:-1]
    valeurs = [t.strip().strip("\"'") for t in brut.split(",") if t.strip()]
    return " · ".join(valeurs[:maximum])
```

```python
def rend_carte(requete, sortie, dry_run):
    """Rend une carte via generate.sh puis la quantifie en PNG8."""
    if dry_run:
        print(f"    rendrait {sortie.relative_to(ROOT)}  ({requete})")
        return
    subprocess.run(
        [str(GENERATE), "-o", str(sortie), "-q", requete],
        check=True, capture_output=True, text=True,
    )
    # Le rendu est aplat : 64 couleurs suffisent, sans dithering visible.
    subprocess.run(
        ["magick", str(sortie), "-strip", "-colors", "64", f"PNG8:{sortie}"],
        check=True, capture_output=True, text=True,
    )
```

```css
   Minimal Mistakes rend sa grille en floats — largeurs en pourcentage sur

  height: 100%;
```
